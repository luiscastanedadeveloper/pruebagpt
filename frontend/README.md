# Frontend (React Skeleton)

This directory contains a minimal React application skeleton.

- `public/index.html` - HTML entry point.
- `src/` - React source code with a simple placeholder component.
- `package.json` - Example package file with placeholder start and build scripts.

The full frontend build setup (like using Create React App or Vite) is not
included. Install dependencies and run the `start` script to begin development
once a React toolchain is added.
